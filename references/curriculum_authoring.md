# 课程内容创作标准（所有证书课程通用）

> 目标读者：填 `cert.json` 的人（作者本人或 AI）。构建器会拒绝任何含 `__TODO__` 的内容，
> 但"填了"不等于"合格"——以下是合格线。

## 1. 事实纪律（最高优先级）

1. **不虚构官方政策**：资格要求、考试题量、时长、费用、再认证规则，一律以发证机构官网为准；写不准就查，查不到就删。
2. **数值必须核对**：限值、换算率、时长、百分比（如 OSHA 5 dB 交换率、TLV、动作水位）。改一处数值要能说出出处。
3. **官方不公开历年真题**：所有题目都是"按官方蓝图自编的仿真题"，页面会自动带来源提示框；解析里不得暗示"这是真题"或"会考"。
4. 优先引用：发证机构蓝图/大纲、OSHA、NIOSH、ISO、行业权威指南。

## 2. 双语纪律

- 每个字段中英成对，**逐段对照**，不是摘要翻译。
- 术语用考场英文原文（如 hierarchy of controls、permit-to-work），中文给规范译名。
- 语言要"现场能说出口"：避免长从句，英文避免生僻词。

## 3. 内容标准（每块）

| 字段 | 要求 |
|---|---|
| `zh` / `en` | 主题具体到考试任务，禁止"综合""其他""拓展" |
| `points` | ≥5 条；每条=做法或判断标准（"先定标准再排序"），不是名词罗列 |
| `terms` | 6 个；一个术语一行释义，不用术语解释术语 |
| `scenario` | 真实工作场景；四选项中干扰项是"常见但不对"的做法；解析讲"为什么" |
| `practice` | 2 条简答，能让学习者带回现场输出（写一条标准、列三项清单） |
| `memory` | ≤14 字中文口诀，可押韵但不得牺牲准确性 |

## 4. 块计划纪律

- 领域分配已按权重自动生成，**不要私自改 `domain`**；如需调整，改 `domains` 权重后重新脚手架。
- 相邻块之间有递进（识别 → 评估 → 控制 → 验证），排块时保持这条线。
- 每块对应 5 课：概念（入门）→ 进阶（应用/算例）→ 术语（考场词汇）→ 情景（判断）→ 复盘（输出）。
  同一块的 5 课共用本块内容，由构建器自动差异化，无需按课写 5 份。

## 5. 质检口径（对照 CSP 的做法）

- 覆盖度：每个 `domain` 下的官方任务描述至少被 1 个块直接覆盖；
- 权重匹配：各领域块数占比与官方权重差 ≤3 个百分点（`audit` 思路，可用简单脚本核对）；
- 数值扫描：全文搜索数字，逐个确认出处；
- 构建后浏览器抽查 1–2 课：判题、导出卡、手机端。
